reclistening only for two words

Say a verb.
Say a noun.

Scarlett is a SAPI-based voice assistant for Windows. It listens for phrases with the grammar [name] verb noun — e.g. “wake computer” — and runs whatever action that phrase is bound to in a YAML configuration file. This is an experimental application that gave Enso its speech recognition abilities.

01what-it-is

Windows speech recognition works surprisingly well with an inexpensive microphone array. Scarlett is what happens when you point that recognizer at a YAML file instead of a dictation box: control a serial port, a magic packet, an HTTP request, a script of your own.

Scarlett is a yet another ubiquitous command interface — one in the line of Enso and Ubiquity, but spoken rather than typed.

02grammar

A phrase is a verb and a noun.

The shape never varies: an optional assistant name, a verb, a noun. Both words come from your config, which is the whole grammar the recognizer is given.

scarlettname · optional wakeverb computernoun

The name is off by default (enable_name: false). With it on, nothing is recognized unless the phrase begins with it.

03actions

Nine things a phrase can do.

Every phrase names one action and hands it a few arguments.

readme →
action · arguments
run cmd args maximize maximize_delay Runs a program with the given arguments.
shell-open file menu menu_delay Opens a file in whatever program is associated with it.
url url maximize maximize_delay Opens a URL in the default browser.
wol mac Sends magic packets to wake a host on the network.
http url method headers payload Performs an HTTP request.
sony-ircc host cmd Sends an IRCC command to an IP-controlled Sony TV.
serial port baud dtr presend send Writes to a device on a serial port — an Arduino of your own make, for instance.
simulate-input keys repeat repeat_delay Simulates keystrokes through SendKeys.SendWait.
close-window type Closes the window in the foreground.

Anything else, you write it. Either as a script called through run, or as a C# class copied from the action template, after which the application is rebuilt.

04config

One file, read aloud.

The phrases are a tree: the verb is a branch, the noun a leaf, and the leaf carries the action and its arguments. Nothing else declares a command — what is in the file is what the recognizer listens for.

Values repeated across commands go in vars and are spelled '@@var_name' where they are used. A command marked confirm: true asks out loud before it fires; disabled: true keeps a phrase in the file but out of the grammar. And restrict_by holds back commands while a given process is running — a film playing, say.

settings.yaml → how phrases are written →
settings.yaml
assistant:
  name: scarlett          # the optional first word
  enable_name: false
  min_confidence: 0.6     # drop anything less certain

vars:                      # '@@var_name' expands inside args
  tv_host: 192.168.1.20

actions:
  wake:                    # verb
    computer:              # noun
      action: wol
      confirm: true        # ask before firing
      args:
        mac: 04:7C:16:...
  show:
    box:
      action: sony-ircc
      args:
        host: '@@tv_host'
        cmd: AAAAAgAAABoAAABbAw==

restrict_by:
  processes:               # not while this is running
    - …/mpc-hc64.exe

05notes

An experiment, kept honest.

Scarlett does one narrow thing with an API that has been sitting in Windows for years. What follows is the case for it, and the list of what it will not do.

Why the recognizer already there

Windows speech recognition is accurate with cheap hardware — a PS3 Eye microphone array does the job — and SAPI hands you a grammar object and a confidence score without ceremony.

The grammar is small by construction: a handful of two-word phrases you wrote yourself. That is a far easier problem than open dictation, and it is why a modest setup can be trusted to pull a serial port line or wake a machine.

Nothing is uploaded online, nothing needs an account, and the assistant that off-the-shelf boxes cannot be talked into doing — driving hardware of your own make — is the ordinary case here.

What it is not

It does not talk back. There is no speech synthesis at all.

No wake-word model. The name is just an optional first word in the grammar.

A phrase that is not in the config is discarded in silence.

No interface but a tray icon that allows to pause and resume listening.

Windows only. It is based on .NET Framework and Windows API.

No window.
Just a grammar.
